# Warped Weapons mod for Serious Sam: The Second Encounter





This mod adds weapons from Seriously Warped Deathmatch mod to vanilla Serious Sam: The Second Encounter by replacing EntitiesMP.dll (and Entities\_Custom.dll if Classics Patch by Dreamy Cecil is installed).



**How To Test:**

1. Download the latest release.
2. Extract the folder (not the contents of the folder) to the root folder of your game.
3. Open the "WarpedWeapons-x.x.x" folder (where x is the mod version)
4. Run Install.bat
5. Launch the game :)



New weapons should appear when you activate the /cht\_bGiveAll=1 or "please giveall" cheat. They should also appear in the editor (entities WeaponItem, AmmoItem and AmmoPack).



Please report any issues you find :)
